## 📖 О приложении

Минималистичное приложение для изучения сингальского языка.

### 🔢 Числа (46 + 20)
- Базовые числа от «эка» (1) до «дахаса» (1000)
- Сложные составные: 125, 375, 1500, 2345 и др.
- Колода с фильтрами по группам
- Тренажёр
- Тест из 10 вопросов с рекордами

### 🔤 Буквы (47 знаков)
- Сгруппированы по варгам: горловые, нёбные, черепные, зубные, губные
- Таблица с переворотом карточек
- Знаки гласных (пилли): 14 знаков, меняющих звучание согласных
- Тест в обе стороны: название → буква и буква → название

<td width="50%" valign="top">

## 📖 About

A minimalist app for learning the Sinhala language.

### 🔢 Numbers (46 + 20)
- Basic numbers from "eka" (1) to "dahasa" (1000)
- Advanced composites: 125, 375, 1500, 2345, etc.
- Deck with group filters
- Trainer
- 10-question quiz with records

### 🔤 Letters (47 signs)
- Grouped by vargas: gutturals, palatals, retroflexes, dentals, labials
- Table with flippable cards
- Vowel signs (pilli): 14 signs that change consonant sounds
- Bidirectional test: name → letter and letter → name
